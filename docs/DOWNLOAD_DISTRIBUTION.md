# Distribution APK — Ouedna Admin 2

La release `admin-v2.0.0` est publiée dans le dépôt GitHub `nadjimyahiaoui1992-lab/ouedna-admin`.

Au 15 août 2026, ce dépôt est privé. Les URL de téléchargement GitHub Releases renvoient donc une réponse HTTP 404 pour les visiteurs qui ne disposent pas d’un accès GitHub autorisé.

Pour remettre un lien APK GitHub téléchargeable à tous, il faut rendre ce dépôt public. Cette action rend également son code source, ses releases et ses tickets visibles publiquement. Une solution alternative consiste à héberger uniquement les fichiers APK dans un stockage public séparé.
